# Фрейд — поиск по книгам

Статическое русскоязычное приложение для поиска по текстам Фрейда. Оно работает без API-ключа: ищет ключевые слова и связанные понятия в `corpus.json`, показывает подходящие фрагменты и страницу для источников PDF. Пояснение ориентирует по найденным цитатам, но не генерирует свободный ответ на любой вопрос и не является клинической консультацией.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите `index.html` и `corpus.json`.
2. В **Settings → Pages** выберите публикацию из ветки `main`, папка `/ (root)`.
3. Откройте выданную ссылку GitHub Pages.

## Состав указателя

В этом корпусе 9 465 фрагментов из 21 источника: PDF- и RTF-файлы, а также HTML/RTF из предоставленных архивов. Страницы PDF сохранены.

Отдельные старые файлы `.doc` и DjVu не попали в этот указатель: для их чтения требуется конвертер этих форматов. Чтобы получить индекс по ним, сначала преобразуйте книги в PDF с распознаваемым текстом или в TXT, затем пересоберите `corpus.json`.

Перед загрузкой корпуса в публичный репозиторий проверьте права на распространение конкретных переводов и изданий. При необходимости используйте приватный репозиторий.
## Офлайн-доступ на телефоне

Приложение можно установить как PWA. Сначала опубликуйте репозиторий через GitHub Pages и откройте сайт на телефоне с интернетом. Дождитесь загрузки корпуса (около 17 МБ), затем выберите в меню браузера «Добавить на главный экран» (Safari: «Поделиться» → «На экран Домой»). После первой полной загрузки приложение и книжный указатель будут доступны без сети.
